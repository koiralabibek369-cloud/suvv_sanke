# Suvv Snake

A small browser-based snake game built with HTML, CSS, and JavaScript.

## Play locally

1. Open `index.html` in a browser.
2. Press the Start / Restart button or hit the spacebar.
3. Use the arrow keys or WASD to control the snake.

## Goal

Eat the orange food and grow as long as possible without colliding with the walls or yourself.

## Files

- `index.html` – page layout
- `style.css` – game styling
- `script.js` – game logic

## Optional

This project can be uploaded to GitHub Pages or served from any static hosting provider.
